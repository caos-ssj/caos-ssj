## En qué estoy metido ahora

### Crypto Bot — bot autónomo de trading de memecoins en Solana

Pipeline completo: detección (DexScreener) → análisis on-chain (Helius) → 11
filtros ponderados + IA local (Qwen3) → ejecución real (Jupiter) con gestión de
riesgo TP/SL/trailing y dashboard en vivo (Streamlit).

- Repo: [Crypto.Bot](https://github.com/caos-ssj/Crypto.Bot)
- Estado: en desarrollo · 130 tests · cobertura 67 % · licencia GPL-3.0
- Principio del proyecto: **scoring honesto** — si un dato on-chain no se puede
  verificar, puntúa 0 (jamás se asume que un token es seguro por falta de datos).
